Add a `github-actions` topping that writes `.github/workflows/ci.yml` with your choice of `lint`, `build`, `typecheck`, and `test` jobs. In `chanom brew` it is a topping option; in `create-chanom-app` it is a prompt plus the `--github-actions` / `--no-github-actions` / `--ci-jobs` flags.
